# TP1 - Microarquitectura OrgaSmall

Trabajo práctico de **Tecnología Digital II** enfocado en el análisis y modificación de una microarquitectura implementada en **Logisim**.

El proyecto consistió en trabajar con el procesador *OrgaSmall*, programando en lenguaje ensamblador, analizando el funcionamiento interno de la arquitectura y agregando nuevas instrucciones al set de instrucciones original mediante microprogramación (microinstrucciones).

Además, se desarrollaron funciones en ASM y conceptos relacionados con memoria, registros, stack, ciclos de clock y ejecución de microinstrucciones.
